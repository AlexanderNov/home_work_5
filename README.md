Веб-сайт с обзорами различных товаров.


Пользователь сайта может:
- зарегистрироваться на сайте (кнопка Register),  
- залогиниться/разлогиниться на сайте (кнопка Login/Logout)
- писать обзоры на различные товары (Имя пользователя > New Review),
- комментировать обзоры других пользователей (выбрать обзор, написать комментарий и нажать Post Comment),
- ставить лайк или дизлайк обзорам других пользователей (нажать на соответсвующую кнопку под обзором),
- может редактировать или удалять свои обзоры (нажать на свой обзор > выбрать из выпадающего списка "Actions" Edit или Delete).


Запустить app.py и пройти по ссылке http://127.0.0.1:5000/
